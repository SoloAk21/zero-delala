# Zero Delala (ዜሮ ደላላ)

Production-ready Telegram Mini App for the Ethiopian Real Estate Market.

## Architecture Overview

- **Frontend**: React, Vite, TypeScript, Tailwind CSS, Telegram Mini Apps SDK
- **Backend**: Node.js, Express, TypeScript, Prisma ORM, PostgreSQL (Neon)
- **Bot**: Telegraf (TypeScript)
- **Shared**: Common TypeScript Types, Zod Schemas, and Constants
